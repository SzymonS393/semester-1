# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | lists files and directories |
|     cd directory_name       | changes the current directory to the specified one |
|     cd ..                   | move up one directory level |
|     cd -                    | switch to the previous directory |
|     mkdir directory_name    | makes a new directory with the specified name |
|     touch filename          | updates file timestamps or creates new files if filename does not exist |
|     git status              | shows the status of the github working tree |
|     git add -A              | adds the content of a file to the github index |
|     git commit -m ""        | records the file changes to the depository |
|     git push                | updates the remote references |
|     git pull                | integrate changes from a remote repository |
